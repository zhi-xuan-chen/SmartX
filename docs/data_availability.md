# Data Availability

This repository does not contain private clinical data or full benchmark datasets.

## Public Data

Public datasets used in the manuscript should be obtained from their original providers and cited according to their licences and access terms. Dataset-specific path templates are provided only as examples.

## Private Data

The private clinical cohort is not redistributed because it contains sensitive clinical data governed by institutional approvals and data-use restrictions. The release code provides method implementations and expected input schemas, but not private images, reports, labels, or splits.

## Demo Assets

Demo assets under `demo/assets/` must be public-domain, openly licensed, or synthetic/de-identified examples. Add source and licence details in `demo/assets/README.md` before public release.
