# Data Availability

This repository contains code and public-domain demo examples only; it does not redistribute private clinical cohorts or full public benchmark datasets.

## Data Categories

| Category | Availability |
| :--- | :--- |
| **Public Benchmarks** | Obtain directly from original dataset providers under their respective licenses and access terms. YAML configs provide placeholder paths only. |
| **Private Clinical Cohorts** | Not redistributed due to patient privacy regulations, institutional ethics approvals, and data-use agreements. Expected input schemas are documented in each task guide. |
| **Demo Assets** | Public-domain / CC0 radiographs and synthetic demo reports under [`demo/assets/`](../demo/assets/README.md), with full source and license provenance. |
