# Report Generation

This directory contains release code for the SmartX LLaVA-Rad report-generation experiments.

Included:
- LLaVA-Rad integration scripts and utilities
- lightweight training/evaluation configs and shell entry points

Not included:
- generated reports, prediction JSONL files, checkpoints, W&B runs, full datasets, vendor build artifacts, or generated result tables

Before running, replace `${SMARTX_DATA_ROOT}`, `${SMARTX_OUTPUT_ROOT}`, `${SMARTX_STORAGE_ROOT}`, and checkpoint placeholders with local paths that you are allowed to use.
